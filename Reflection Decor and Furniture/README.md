# PulseFit Fitness Center – Website Redesign

# Project Overview

This project was created as part of the FUTURE UX Internship – Task 01.


The objective was to redesign the website of a local service business with a focus on improving user experience, increasing lead generation, and encouraging conversions. PulseFit Fitness Center was chosen as the case study, with the redesign emphasizing clear navigation, membership visibility, and an intuitive contact process.

# Project Goals

- Improve the overall user experience
- Present services in a clear and organized manner
- Highlight membership plans
- Encourage users to start a free trial
- Increase lead generation through a dedicated contact page
